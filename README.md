# Neste projeto utilizei Playwright com TypeScript para automatizar testes de login na aplicação SauceDemo

## Os cenários automatizados foram:
✅ Login com sucesso  
✅ Login com usuário bloqueado  
✅ Login com username inválido  
✅ Login com senha inválida  

## Durante a execução utilizei o Playwright Test UI para acompanhar os testes em tempo real, analisar os resultados, verificar falhas e facilitar o processo de depuração.

## Esse projeto me permitiu praticar conceitos importantes como:
🔹 Criação de testes automatizados  
🔹 Localização de elementos (Locators)  
🔹 Validação de mensagens de erro  
🔹 Verificação de URL e elementos da página  
🔹 Uso de assertions com expect  
🔹 Organização de testes utilizando o Playwright Test.
